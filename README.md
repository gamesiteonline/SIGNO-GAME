# SIGNO - A LIMBO Tribute

SIGNO is an atmospheric 2D puzzle-platformer developed as a tribute to the minimalist, silhouette-based aesthetic of LIMBO. 

## Features
- **20 Intensive Stages:** Long, challenging levels with diverse themes (Forest, Industrial, Cave, Graveyard, Void).
- **Cinematic Experience:** High-contrast visuals, dynamic lighting, and an eerie ambient soundtrack.
- **LIMBO-Inspired Enemies:** Encounter giant spiders, abyssal creatures, and lethal mechanical hazards.
- **Intensive Settings:** Customize your experience with Bloom, Film Grain, Motion Blur, and more.
- **Responsive Controls:** Fully playable on Desktop and Mobile.
